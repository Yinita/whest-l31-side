# R46 oracle state reset orientation audit

`tenfold_oracle_orientation_contract_r46_r01.json` independently checks the canonical/internal mapping on synthetic finite ReLU samples, without labels/reference. H18 internal output order is canonical[perm]; inv_perm=argsort(perm), so the returned/captured canonical row is internal[inv_perm]. Inserting canonical oracle truth therefore requires truth[perm], or truth[argsort(inv_perm)]. A non-self-inverse cyclic permutation deliberately prevents a mistaken inverse insertion from passing a swap-only test. Negative control errors are.384–3.155 across widths8/32/1024.

At each next linear map, H18 canonical weight axes are input rows and output columns. Current internal weights are w[previous_perm][:,current_perm]; this transports a previous internally ordered mean to the current internal mean. The dual-axis contract matches canonical transport to<=3.11e-15; using the previous inverse instead produces errors1.35–4.68. This is independent synthetic evidence for the existing parent permutation orientation.

Raw moments are first promoted to float64, then central quantities formed: variance=m2−m1²; κ3=m3−3m1m2+2m1³; κ4=m4−4m1m3+6m1²m2−3m1⁴−3variance². Finite-sample centered checks match to<=6.85e-13. Conversion then float32 commutes exactly with permutation. Original mixed K21/K22 and original raw birth pk1/e_b ledger are retained. Correct K1 stores oracle output mean minus any inherited deterministic rider; parent assembly adds that rider once. Float32 copied K1 plus rider can differ from desired float64 oracle mean by~1.11e-7 in the1024synthetic test.

`tenfold_oracle_source_audit_r46_r01.json` records read-only inspection of immutable `modal_joint_oracle_reset_r46.py`: worker truth loads float64, injection uses truth[argsort(inv_perm)], capture uses [inv_perm], reset only layers1..14, analytic Gaussian layer0 and final layer15 untouched, and raw-central host formulas correct. `after_states` stores the desired float64 updated truth in canonical order, rather than capturing actual copied float32 state; do not call that array exact live-state proof.

R46 is an offline oracle diagnostic only. It uses MC corpus labels and is inadmissible as a production estimator. Exact marginal oracle diagonals with original approximate cross/source histories need not describe one joint distribution, can amplify MC noise, and cannot repair every covariance/higher-source transport error. The experiment probes mechanism headroom; it is not a competition score, achieved upper-bound algorithm, independent validation or tenfold-stage evidence.
