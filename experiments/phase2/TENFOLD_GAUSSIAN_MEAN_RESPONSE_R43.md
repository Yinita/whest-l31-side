# Fixed-variance Gaussian mean transport response

The target-free component `tenfold_gaussian_mean_response_r43.py` uses permitted flopscope arithmetic and normal pdf/cdf. For preactivation mean μ, standard deviation σ and inherited transport h=W e_previous, Gaussian ReLU mean is M(μ,σ)=σφ(μ/σ)+μΦ(μ/σ). The fixed-variance exact response is M(μ+h,σ)−M(μ,σ). Its first derivative is Φ, so the inherited postmean response is Φ*h to first order, not bare h. The second-order response adds .5*(φ/σ)*h².

`results/phase2/tenfold_gaussian_mean_response_contract_r43_r02.json` checks synthetic widths8/32/1024, with no labels, fitting or competition reference. Zero shift gives exact zero; base formula versus independent standard-library erf differs by<=1.03e-14; centered-difference derivative versus Φ differs by<=3.41e-11. Halving normalized shift magnitude from.08 to.005 gives observed first-order remainder order1.994..1.9999 and second-order remainder order2.985..3.016. Ungated h is an explicit negative control and is more than10times the first-order remainder; composing responses using the updated base gives the exact combined shift, while using a static base twice fails. Full evaluation of exact/first/second responses at1024 costs600,064 FLOPs; this is a component cost, not whole production resource acceptance.

The initial1e-14 error tolerance failed at1.11e-14 between flopscope norm and stdlib erf and is preserved as `tenfold_gaussian_mean_response_contract_r43_failed_r01.json`; tolerance was adjusted to5e-13 with unchanged formulas. This repair is numerical-library tolerance, not algorithm gain.

This supplies only a fixed-variance Gaussian local response. For a real non-Gaussian ReLU preactivation, its Jacobian is P(X>0), which need not equal the Gaussian Φ approximation. An actual pre-ReLU shift also changes output covariance, mixed cumulants and source births; those transformations are omitted here. It does not establish a full causal-state closure, a trained candidate, a closed-rollout improvement, strict resource acceptance or tenfold score gain.

Estimated postmean clamping is distinct from clipping random outputs. The floor max(μ+b,0) merely chooses deterministic b_eff=max(μ+b,0)−μ, so represented central cumulants stay unchanged. Individual sample clipping changes central moments; a nonnegative estimated mean alone does not ensure ReLU support.
